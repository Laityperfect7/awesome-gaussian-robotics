# Changelog

All notable changes to Gaussian Robotics Atlas are documented here. The project uses
[Semantic Versioning](https://semver.org/) for its Python interface and dated catalog
snapshots for data changes.

## [0.1.0] - 2026-08-30

### Added

- 61 evidence-checked resources across Gaussian mapping, SLAM, semantics, navigation,
  manipulation, dynamic scenes, simulation, robot learning, tooling, and benchmarks.
- A zero-runtime-dependency CLI for validation, search, explainable recommendations,
  statistics, and deterministic builds.
- Generated Markdown, JSON, CSV, statistics, and a self-contained searchable site.
- Practical guides for stack selection, ROS 2 boundaries, real-to-sim/VLA workflows,
  evidence review, and honest benchmarking.
- Strict type, taxonomy, duplicate DOI/arXiv/GitHub, URL-safety, and stale-evidence checks.
- Formula-safe CSV export and redirect-aware public-network protection in the scheduled
  link checker.
- JSON Schema, unit and integration tests, coverage/type/lint gates, GitHub Pages, issue
  forms, and a documented contribution process.
